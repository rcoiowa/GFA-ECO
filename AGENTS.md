## Non-negotiables (summary; the documents above govern)

- Prepared → apply is gated: no migration application, deployment, production permission change, or
  external communication without explicit authorization. A design or migration plan is not permission
  to modify production.
- Distinguish GFA, RCO Iowa, RecoveryOS, Iowa's Recovery Community Center, the Recovery Community /
  Residence apps, Grace House, and EJWRH (not a GFA house). Infer no ownership or partnership from
  collaboration or shared technology.
- Never fabricate facts, metrics, citations, or technical state. Distinguish proposed / approved /
  prepared / tested / deployed / verified-in-production. A green build or tool response is not proof
  the user journey works.
- Minimum-sufficient data; least privilege; never put credentials, tokens, or participant details in
  public outputs, screenshots, repositories, or logs.
