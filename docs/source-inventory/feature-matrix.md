## Duplication resolutions this matrix enforces

- **One check-in system** (canonical engine; was 4 implementations).
- **One recovery capital instrument flow** (was 3).
- **One residence subsystem** (Residence OS `gfa_residence` lineage; Grace House build
  contributes content/brand only).
- **One person record** (live `gfa_ui.participant_profiles` spine reconciled to
  canonical `people` in Phase 8 — never both active at once).
- **One Grace AI**, **one Walls of Honor**, **one resource directory**.
